# Daily Signal

Daily Signal is a dark, responsive cybersecurity explainer site with a daily feature, section filters, site search, individual article views, a source list, and an editorial transparency page. Its seven evergreen explainers rotate weekly. This is not a live news service.

## Live site

https://news.yashmaheshwari.fyi/

The repository `CNAME` file keeps the custom domain attached to GitHub Pages on each deployment. In Cloudflare DNS, create a `CNAME` record with name `news`, target `serdire.github.io`, and proxy status **DNS only** while GitHub verifies the domain and provisions HTTPS. The `yashmaheshwari.fyi` zone must already be active on Cloudflare nameservers. DNS and HTTPS activation can take time after the record is added.

## Daily publishing

GitHub Actions runs the workflow at 05:23 UTC each day. It selects an article using the UTC calendar date, records the featured date in `current.json`, commits that update, and deploys the static site to GitHub Pages. It needs no AI API key, runtime server, or external content API.

The site is deployed from the repository root using GitHub Actions. The workflow runs the tests on pushes and before its scheduled update. Run the same checks locally with `node --test`; preview the website with any local static HTTP server.

## Editing the briefing

Add or edit explainers in `articles.json`. Every entry includes a unique route slug, section, headline, summary, reading time, full article paragraphs, takeaways, and a primary source URL. Keep source links and claims accurate; articles are published as evergreen guidance rather than real-time reporting. `current.json` is generated by `node scripts/publish.js` and should not be edited by hand.

## Current scope and limitations

- Seven source-linked educational explainers; the cycle repeats every week.
- No live news ingestion, AI-generated writing, accounts, comments, newsletter, or content-management dashboard.
- GitHub scheduled workflows can be delayed or paused, and an automated commit does not guarantee a contribution streak. GitHub's contribution rules, account attribution, workflow availability, and daily execution all matter.
- This is a learning project, not an emergency alert or professional incident-response service.
